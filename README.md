# Serbaguna

Kumpulan alat gratis untuk kebutuhan sehari-hari. Dibuat sebagai website statis, tanpa backend dan tanpa login.

## Fitur
- Penghitung kata, karakter, dan estimasi waktu baca
- Generator password acak menggunakan Web Crypto API
- Kalkulator persentase
- Kalkulator diskon
- Konversi suhu Celsius/Fahrenheit/Kelvin
- Catatan cepat dengan fitur salin

## Menjalankan secara lokal
Buka `index.html` di browser modern.

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `serbaguna`.
2. Unggah `index.html` dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses selesai. Website akan tersedia di URL GitHub Pages yang ditampilkan.

Semua kalkulasi dan pemrosesan teks dilakukan di browser. Tidak ada data yang dikirim ke server.
